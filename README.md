# AI Face Studio — Native Android

Native Kotlin + Jetpack Compose app by PaliaAPK HUB / Developer By ShanPalia.

## Included
- Native Home screen and bottom navigation (Home / History / Profile).
- Native entry screens for Photo, Video, GIF and Multiple Face workflows.
- Android system file picker for target media and replacement portrait.
- Selected image preview and consent reminder.
- GitHub Actions workflow to build a debug APK.

## AI backend status
AISWAPFACE describes itself as a browser-based service. No public native API contract or credentials have been verified for this integration. This project does not scrape private endpoints or claim to perform swaps without a real service. To enable actual photo/video/GIF processing, obtain written permission and official API documentation from the service operator, or integrate a separately licensed AI backend. Keep secret API credentials on a server, never in the APK.

This is a native Android UI starter, not yet a feature-equivalent replacement for the website's server-side AI processing.

## Build using GitHub Actions
1. Open the repository Actions tab.
2. Select "Build AI Face Studio Native APK".
3. Click "Run workflow".
4. Download the AI-Face-Studio-Native-debug artifact from the successful run.
5. Extract the ZIP and install app-debug.apk.
